# M1：Windows 本地启动与配置预检

日期：2026-10-27。基线：v0.5 Phase commit `538c9ce`，含已合并 M0 与最小 M2。

## 目标

双击仓库根目录入口，检查本地 Python/Node/Web 依赖、LLM 配置和服务端口，
启动本地 API 与前端并打开实训页。默认使用规则 Tutor；可通过被 Git 忽略的
`.env.local` 或环境变量启用现有 Provider。

## 本任务范围

- 根目录一个 Windows `.cmd` 入口和一个 Python 启动器。
- 一个窄格式配置示例及 README 的首次安装/启动说明。
- 预检只读已有 Provider Settings/Registry，不另造模型配置规则。
- API 固定监听 `127.0.0.1:8001`，Web 固定监听 `127.0.0.1:5174`。
- 遇到占用端口立即给出处理提示；不接管、不关闭、不复用未知进程。
- 只关闭由当前启动器创建的 API/Vite 进程。
- Key 只进入 API 子进程；配置、状态和错误信息不输出 Key。
- 启动健康后打开浏览器，支持 `--check-only`、`--no-browser` 和 `--config`。
- 真实 Provider smoke 使用已有 `tools/deepseek_tutor_smoke.py` 单独运行；不在启动器、
  自动化 CI 或双击启动时自动发起付费网络请求。

本任务不改 API、Schema、Core、评分、Provider 实现、前端产品流程和 SQLite。
不自动安装依赖、不构建/部署生产站点、不设置 HTTPS、不创建备份或云服务。

## 验收

1. 无 LLM 凭据时预检和本地启动走规则回退。
2. Key 配置在 API 可用，不进入 Web 子进程、命令行参数、启动器输出或 Git 跟踪文件。
3. 错误配置、缺少运行依赖、任一固定端口占用都在启动子进程前失败并显示可操作提示。
4. 两服务启动失败或退出时，启动器关闭本轮创建的另一服务。
5. 正常启动打开本地实训页；Ctrl+C 只清理本轮创建的服务。
6. 已有 DeepSeek smoke 仍为显式、凭据门控动作；真实人工验收和 M3 生产构建不属于本任务。
