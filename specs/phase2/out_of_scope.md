# Phase 2 Out of Scope

- FastAPI routes or HTTP server;
- SQLAlchemy/SQLite persistence;
- full Diagnostic State Machine or legal transition table;
- persistent Session Trace repository;
- Skill score calculation or `scoring_rules` interpretation;
- automatic Case recommendation or cross-session Skill aggregation algorithm;
- Tutor Policy, LangGraph, LLM API, prompts or RAG;
- frontend/UI;
- Mock/Isaac/Gazebo implementation;
- fault injection, Episode Recorder or Case generation;
- bulk creation of 8–12 Cases;
- changes to Phase 1 Schema/API without a reviewed Contract Change Proposal.

If implementation requires any item above, stop and return to the appropriate Spec/Contract owner.
