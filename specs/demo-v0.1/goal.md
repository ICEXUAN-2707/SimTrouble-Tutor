# Demo v0.1 Goal

> Status: APPROVED FOR IMPLEMENTATION

Deliver a reproducible, clearly labeled initial ST-001 browser Demo that runs on the official Phase 3 Core without duplicating project source or claiming unimplemented V0 capabilities.

The Demo must let a reviewer:

1. open the ST-001 scenario;
2. inspect released Evidence;
3. add and update a Hypothesis;
4. ask a deterministic rule-based Tutor;
5. submit the Demo-only ST-001 diagnosis;
6. view the authoritative Core Trace generated by those commands;
7. reset the in-memory session.

Success means one-command startup, an automated ST-001 HTTP E2E test and a real subprocess startup smoke test all pass together with the existing 57 Core regressions.
