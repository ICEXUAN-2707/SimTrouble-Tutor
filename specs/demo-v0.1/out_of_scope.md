# Demo v0.1 Out of Scope

- changing frozen JSON Schemas or public API/Tutor/Simulation contracts;
- new Core stages, transitions, guards or automatic stage advancement;
- Skill scoring, five-dimensional reports or recommendations;
- LangGraph, LLM API, RAG, embeddings or online Tutor calls;
- FastAPI, Next.js, React or TypeScript migration;
- Mock Simulation, Gazebo, Isaac, ROS or real device control;
- SQLAlchemy, SQLite, repository interfaces or restart recovery;
- accounts, authentication, authorization, remote hosting or multi-user guarantees;
- Case expansion beyond ST-001;
- treating the Demo-only diagnosis judge as a formal scoring or diagnosis engine;
- copying the `zjh/` source tree into the repository;
- release to `main` or tagging; those require a separate release gate.

If implementation requires any item above, stop and create the corresponding Phase Spec or Contract Change Proposal.
